## 🎯 开发顺序建议

### 第一阶段：基础底座（1-2周）

1. 配置环境（Debian + Python + uv）
2. 数据库设计（MySQL + Milvus）
3. 用户认证模块开发
4. 通用工具封装

### 第二阶段：AI能力（2-3周）

1. LLM调用封装
2. 向量嵌入服务
3. RAG知识检索模块
4. Mineru文档处理集成

### 第三阶段：核心业务（3-4周）

1. 赛事推荐与组队模块
2. 智慧地图模块
3. 校园论坛模块

### 第四阶段：联调优化（2周）

1. 模块联调
2. 体验优化
3. 异常处理完善

| HTTP客户端 | Axios |
| AI服务 | OpenAI兼容API |
| 文档处理 | Mineru |
