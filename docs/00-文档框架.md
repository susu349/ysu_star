## ✅ 每个模块文档包含的核心要素

每个模块文档必须包含以下**可落地**的精细内容：

| 要素 | 说明 |
|-----|------|
| 🏗️ 模块架构 | 模块内部分层、子模块划分 |
| 🚪 入口说明 | 如何进入该模块、路由配置、菜单配置 |
| ⚙️ 运转机制 | 模块内部如何运转、状态流转 |
| 📊 数据流 | 数据如何流入、处理、流出 |
| ✅ 数据标准 | 什么样的数据是合格的、校验规则 |
| 📝 落地步骤 | Step-by-Step 实现步骤 |
| 🔗 上下游依赖 | 依赖哪些模块、被哪些模块依赖 |
| 🧪 测试验收 | 如何测试、验收标准 |

## 🎨 流程图样式规范

所有 Mermaid 流程图统一使用以下样式：

- **边框颜色**：黄绿色 (`#9ACD32` / `#B8860B`)
- **背景颜色**：淡蓝色 (`#E6F3FF` / `#F0F8FF`)
- **节点样式**：圆角矩形，边框加粗
- **连线样式**：带箭头，清晰指示流向

示例样式代码：
```mermaid
flowchart TD
    classDef node fill:#F0F8FF,stroke:#9ACD32,stroke-width:2px,rx:8px
    classDef startend fill:#E6F3FF,stroke:#B8860B,stroke-width:3px,rx:10px
```
