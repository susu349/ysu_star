## 安全建议

1. **尽快轮换 API密钥**：当前 .env 中的 DeepSeek API key可能已经泄露，建议立即更换
2. **生产环境配置**：
   - 不要使用默认的 JWT_SECRET_KEY
   - 配置适当的 CORS 来源（不要用 "*"）
   - 强制 HTTPS
3. **数据库安全**：
   - 使用强密码
   - 限制数据库用户权限
   - 不要把 .env 文件提交到git

## 运行提示

1. **后端启动**：
   ```bash
   cd backend
   uv sync
   uv run python -m campus_ai.main
   ```

2. **前端启动**：
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **数据库初始化**：
   - 使用 `backend/scripts/` 中的脚本初始化数据
