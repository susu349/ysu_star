# 校园AI助手 - 启动指南

## 📋 前置条件检查

在启动项目之前，请确保已安装以下软件：

- [ ] Python 3.11+
- [ ] uv (Python包管理工具)
- [ ] Node.js 18+
- [ ] MySQL/MariaDB 10.0+
- [ ] Docker & Docker Compose (可选，用于Milvus向量数据库)

## 🚀 快速启动（3步）

### 第1步：启动后端服务

```bash
# 进入后端目录
cd backend

# 复制配置文件（如果没有）
cp .env.example .env

# 编辑配置文件，填入MySQL等配置
# 注意：确保数据库已创建！

# 安装依赖（首次运行）
uv sync

# 初始化数据库（会自动创建表）
uv run python -c "
import sys
sys.path.insert(0, 'src')
from campus_ai.core.database import engine
from campus_ai.models.user import Base
Base.metadata.create_all(bind=engine)
print('✅ 数据库初始化成功')
"

# 启动后端服务
uv run python -m campus_ai.main
```

后端服务启动后，可以访问：
- API文档: http://localhost:8000/docs
- API首页: http://localhost:8000/

### 第2步：启动前端服务

打开一个新的终端窗口：

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务
npm run dev
```

前端服务启动后，可以访问：
- 应用首页: http://localhost:5173

### 第3步：验证运行

1. 访问 http://localhost:5173
2. 点击注册，创建测试用户
3. 登录并使用各项功能

## 🐳 Docker方式启动（可选）

## 🔧 常见问题

### 后端启动问题

**问题：MySQL连接失败**
```
解决：
1. 确认MySQL服务已启动
2. 确认.env文件中的数据库配置正确
3. 确认数据库已创建：CREATE DATABASE campus_ai;
```

**问题：uv命令不存在**
```
解决：
安装uv: curl -LsSf https://astral.sh/uv/install.sh | sh
或访问 https://docs.astral.sh/uv/getting-started/installation
```

### 前端启动问题

**问题：npm依赖安装慢**
```
解决：
使用国内镜像：
npm config set registry https://registry.npmmirror.com
```

**问题：端口被占用**
```
解决：
找到占用进程：
Linux/Mac: lsof -ti :5173 | xargs kill -9
Windows: netstat -ano | findstr :5173，然后结束进程
```
