# 🚀 校园AI助手 - 快速启动指南

## ✅ 环境已就绪！

后端配置已修复，可以正常启动了。

---

## 快速启动（3步）

### 第1步 - 启动后端

打开一个新终端：
```bash
cd backend
uv run python -m campus_ai.main
```

后端将启动在：http://localhost:8000

### 第2步 - 启动前端

打开另一个新终端：
```bash
cd frontend
npm install  # 首次运行
npm run dev
```

前端将启动在：http://localhost:5173

### 第3步 - 开始使用

浏览器打开 http://localhost:5173

---

## 📖 或者使用启动脚本

```bash
# 终端1
./start-backend.sh

# 终端2
./start-frontend.sh
```
